## P. Especificación para la aplicación sustituta (Angular/Spring Boot)

Para reproducir esta funcionalidad:

1. **Entidad/consulta:** Catálogo maestro `DATOS_GENERALES_CONTRIBUYENTE` (o equivalente) con campos: `RAZON_SOCIAL`, `RFC`, `NUMERO_IMMEX`, `DOMICILIO_FISCAL`. Esperar 0 o 1 registro por empresa/RFC.
2. **API:** Endpoint GET para obtener registro(s) con soporte de filtros por los 4 campos (operadores básicos: contains/equals/startsWith). No requerir paginación compleja si es único.
3. **UI (Angular):** Tabla/grid con filtros por columna, estado "sin datos", paginador. Botones Nuevo/Guardar/Eliminar controlados por permisos (no hardcodear visibilidad por rol sin RBAC).
4. **Validaciones:** `Valida()` debe migrarse a validaciones servidor-side; `Temporalidad en meses` es numérico (max 3 dígitos) si se habilita el panel.
5. **Seguridad:** Eliminar requiere confirmación; acciones de escritura deben ir por SP (regla SP-first del proyecto) y validar permisos.
6. **Errores:** Mostrar modal de error consistente; evitar mixed content (usar HTTPS).
