# 04 — Comparación de requisitos (RF-001..RF-056) contra la implementación Angular + Spring Boot

- **Alcance:** trazabilidad funcional de cada requisito de `03-matriz-requisitos.md` contra el código del repositorio del proyecto (Angular 22 en `frontend/src`, Spring Boot 4.1 en `backend/src/main/java`, procedimientos en `infra/sql`).
- **Modo:** solo lectura. No se modificó ningún archivo del repositorio. No se ejecutó Git ni la aplicación.
- **Fecha de consolidación:** 2026-10-20.
- **Método:** para cada RF se buscó el equivalente en rutas, componentes, servicios, controladores, adaptadores y procedimientos almacenados; se clasificó según la evidencia encontrada y se registró `archivo:línea`.
- **Regla de clasificación:**
  - **CUMPLE** — la funcionalidad existe con evidencia directa y satisface el enunciado.
  - **PARCIAL** — existe la funcionalidad base pero falta o diverge una parte verificable del enunciado (columnas, permisos, formato, fase, granularidad de filtro).
  - **NO CUMPLE** — no existe implementación de lo exigido (o existe y contradice el enunciado).
  - **NO VERIFICABLE** — no hay evidencia en el repositorio que permita emitir un juicio en uno u otro sentido.
- **Convención de evidencia:** `ruta/relativa/archivo.ext:línea` (o `:línea-línea`). Rutas relativas a la raíz del repositorio. `frontend/...` = `frontend/src/app/...` cuando el archivo está bajo `app`.

## 5. Observaciones de método y límites

1. **No se ejecutó la aplicación ni la base de datos.** Todas las clasificaciones provienen de lectura de código fuente y de los procedimientos versionados en `infra/sql`. Ningún volumen de datos (1128/2632/5039 registros) fue contrastado contra `CALE_IMMEX` en vivo.
2. **Los SP legacy externos** (`dbo.PR_INFORME_SALDOS` y el dump `db.sql` referenciado en `infra/sql/procedures/queries/APP24_Q_SALDOS_LISTAR.sql:2-4`) no están en el repositorio: las cláusulas de cálculo que dependen de ellos quedan como no verificables dentro de RF-046.
3. **El catálogo de actividades vigente en el seed** tiene 16 claves (`infra/sql/03-app-seed-security.sql:15-35`); no se verificó la existencia de actividades adicionales en `ANEXO24_DEV` en vivo, por lo que el contraste con las 52 claves del legacy se hizo sobre el código versionado.
4. **Los filtros de `CALE_IMMEX` y `ANEXO24_DEV` son de dominio (`@Filtro`, `@Producto`, `@Material`)**, no de presentación por columna con operadores; la ausencia del menú de operadores se considera consistente en frontend y backend, por lo que no hay un lado de la brecha oculta.
5. **No se modificó ningún archivo del repositorio** `cale-anexo24` durante esta auditoría; el único archivo escrito es este documento.
